# VEXXO

Рабочий сайт на GitHub Pages (`index.html`): общий календарь, планы и задачи Ули и Максима, расписание, чертежи Максима. Данные хранятся в Supabase. Адрес: https://max657445.github.io/VEXXO/ (буквы заглавные).

## Как устроено

- Вход по личному коду (4–12 цифр). Сервер выдаёт токен сессии на 30 дней, он хранится только на устройстве; код нигде не сохраняется. В кабинете можно сменить свой код (6–12 цифр) и выйти на всех устройствах.
- К таблицам Supabase нет прямого доступа: всё идёт через SQL-функции, которые проверяют код или токен. Ключ `sb_publishable_…` в `index.html` публичный, это нормально.
- Чертежи: файл можно загрузить только по пути, который база выдаёт Максиму (`vx_file_prepare`); удалённый чертёж стирается и из хранилища.
- Уведомления в Telegram: новая запись или событие от другого человека, ответ на событие, напоминание за час, утренняя сводка в 8:00 по Москве.
- Вкладка «Админ» (только у Максима, сервер проверяет это в каждой функции `vx_admin_*`): сводка; доступ (закрыть сайт для Ули, сбросить её код, выйти за неё на всех устройствах, журнал входов); все записи обоих людей с правкой и удалением, чистка и полная резервная копия JSON; хранилище чертежей и лишние файлы; Telegram (проверка связи, включение и выключение типов уведомлений, ручной запуск сводки и напоминаний, сообщение от сайта); журнал действий.
- GitHub Action `keepalive` раз в два дня пингует Supabase, чтобы бесплатный проект не уснул.
- Установка на экран «Домой»: `manifest.webmanifest` и иконки в `icons/`.

## База данных (Supabase, SQL Editor, по порядку)

1. `supabase/schema.sql`
2. `supabase/migration-2.sql`: планы и задачи друг другу, дата и время у плана
3. `supabase/migration-3.sql`: Telegram (нужен пароль-токен, см. ниже)
4. `supabase/migration-4.sql`: сессии, кабинет, защищённые чертежи, расписание, правка, напоминания, пинг
5. `supabase/migration-5.sql`: админ-меню, журнал действий и входов, закрытие сайта, настройки Telegram

Коды входа задаются отдельно и в репозиторий не попадают:

```sql
select vx_set_code('maxim', '...');
select vx_set_code('ulya', '...');
```

Telegram (токен и номера чатов в репозиторий не кладутся):

```sql
select vault.create_secret('ТОКЕН_БОТА', 'tg_token');
insert into vx_notify(name, chat_id) values ('maxim', ...), ('ulya', ...);
```

Расписание пар вносится на сайте (вкладка человека, «Расписание»).

## Проверка

`python3 tests/smoke.py` — дымовой тест интерфейса с подменой сервера (нужен playwright).

## Чат с Claude

Плавающая кнопка «Спросить Claude» сейчас всегда отвечает фиксированной фразой (`FIXED_REPLY` в `index.html`). Настоящие ответы: ключ Claude API на console.anthropic.com, Cloudflare Worker из `worker/worker.js` (секрет `ANTHROPIC_API_KEY`, переменная `ALLOWED_ORIGIN`), адрес Worker в `CHAT_API_URL`, `FIXED_REPLY` сделать пустым.
