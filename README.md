# VEXXO

Сайт на GitHub Pages (`index.html`).

## Чат с Claude

Кнопка «Спросить Claude» появляется на сайте, когда в `index.html` заполнена переменная `CHAT_API_URL`.
Ключ Claude API нельзя класть в код сайта, поэтому запросы идут через маленький Cloudflare Worker (`worker/worker.js`).

1. Получи ключ на console.anthropic.com (нужна оплата за запросы, обычно копейки за вопрос).
2. На dash.cloudflare.com создай Worker, вставь код из `worker/worker.js`.
3. В настройках Worker добавь:
   - секрет `ANTHROPIC_API_KEY` с ключом;
   - переменную `ALLOWED_ORIGIN` с адресом сайта, например `https://max657445.github.io`.
4. Скопируй адрес Worker (вида `https://vexxo-chat.<имя>.workers.dev`) в `CHAT_API_URL` в `index.html`.

## База данных (Supabase)

Календарь, доски планов и задач и чертежи хранятся в Supabase и общие для Ули и Максима.
Адрес проекта и публичный ключ (publishable) лежат в `index.html`, их можно держать в коде.
Секретные ключи (`secret`, `service_role`) и пароль базы в репозиторий класть нельзя.

Установка (один раз):

1. Supabase -> SQL Editor -> New query -> вставить весь файл `supabase/schema.sql` -> Run.
2. Задать коды входа отдельным запросом (в репозиторий коды не записываем):

   ```sql
   select vx_set_code('maxim', '0000');
   select vx_set_code('ulya', '0000');
   ```

   Вместо `0000` подставить свои цифры (4 цифры). Сменить код можно тем же запросом.

Как это защищено: к таблицам напрямую доступа нет, сайт работает только через функции, которые проверяют код.
После 30 неверных кодов подряд за 5 минут вход закрывается на 5 минут.
Файлы чертежей лежат в публичном хранилище `drawings` и открываются по ссылке с длинным случайным именем.
Загружать и удалять чертежи может только Максим.
